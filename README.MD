### About 
The Lost and Found App is an Android mobile application built for SIT305 Task 7.1P. It connects lost items to their owners by allowing users to post and 
browse lost or found items. Users can easily report items by filling in a form, browse all listings, filter by category, and remove items once they have been returned to their owner.

9.1P 
This follow on task enabled the implimentation of geolocation tjhat allowed users to place exact locations on a map of where they found or lost items. Users are able to insert a location, or have a location put in for them, where pins are visibale on a map to show the location to other users.

### Features
- Create lost or found item posts with details including name, phone, description, date, location, and category.
- Upload an image for each post from the device gallery.
- Automatic timestamp on each listing showing when it was created .
- View all lost and found items in a scrollable list.
- Geolocation to show where users have found lost items.

### Tech Stack
- Java
- Android SDK
- SQLite Database
- RecyclerView with custom Adapter
-Google maps API
